# Lovable Production Flow

برنامج لاداره الانتاج داخل مصنع لصناعه الملابس ، من بدايه اخذ الطلب ثم القص والتطريز والخياطه والجوده والازرار والكوي و تسليمه للفرع


عند تسليمه للشخص الي بعده تسليمه بالاسم او باليوزر يعني توكيل للمهمه مثلا بعد القص تسليمه للخياط X 

مسؤول الجوده امكانيه ارجاع المنتج للتطريز او القص الخ للارجاع على الموظف الي اخطأ بالمنتج

في حال مسؤول الجوده الارجاع للشخص المسؤول ووضع علامه للطلب بخط احمر انه فيه مشكله او تنبيه 

انشاء خط سير متكامل حسب كل منتج ( تصنيفات للمنتجات )

تعديل اسامي الفروع  

يوزر لكل شخص يسجل واعطاء صلاحيات للموظفين والموافقه عليها من الادمن 



ارقام الفواتير تلقائى رقم بعد رقم

امان الموقع وتقفيله ماحد يدخل الا بتسجيل دخول والموافقه عليها من قبل الادمن فقط

This project was built with [Lovable](https://lovable.dev).

## Build with Lovable

Continue developing this project in the [Lovable editor](https://lovable.dev/projects/b3f8401e-ce5d-44c2-b866-099adb5857d7).

- **Ship faster**: describe what you want to build and Lovable handles the code.
- **Stay in sync**: every change made in Lovable is committed straight to this repository.
- **Full ownership**: this code is yours. Push to `main` on GitHub and your changes sync back into Lovable, ready for your next prompt.

## Development

Prefer working locally? You need Node.js and npm — [install with nvm](https://github.com/nvm-sh/nvm#installing-and-updating).

```sh
git clone <this-repository-url>
cd <repository-name>
npm i
npm run dev
```
